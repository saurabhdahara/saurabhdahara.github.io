A Date With You ❤️ — Ready-to-use HTML website

FILES:
- index.html — the complete website
- photo1.jpg ... photo10.jpg — replace these with your photos
- date-photo.jpg — replace with a date/location photo

QUICK SETUP:
1. Put your photos in this same folder.
2. Rename them to the filenames used by index.html, OR edit the filenames in index.html.
3. Open index.html in Chrome to preview it.
4. Search/replace:
   [HER NAME]
   [YOUR NAME]
   [DATE]
   [DAY, DATE]
   [TIME]
   [LOCATION]
5. For free online hosting, upload the folder to a GitHub repository and enable GitHub Pages.

The site is responsive and works on phones.
